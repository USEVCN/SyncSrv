同一台设备只安装一个 Agent，按任务承担 源目录、备份库、归档库和恢复库。存储连接可绑定设备及真实本机目录；同设备复制和 SHA-256 校验由设备本地执行，跨设备优先直连，未开始或确认停止后才允许中心中转。结果不明的执行不会启动第二个写入者。配置、群晖原生套件及验证边界见[设备执行与群晖安装](../docs/设备执行与群晖安装-0.11.md)。

开机自启的源端服务：原生事件 → 本机 bbolt 双队列 → 服务端先显示待执行 → 连续保存合并等待 → 源端直接连接 备份库传输/回读 SHA-256 → 按设备绑定执行归档并由中心提交备份。中心接口只接收控制消息、元数据和回执，不接收源端文件内容。

Windows 使用 SCM，管理员安装后默认以 LocalSystem 系统账户运行，普通本地目录通常无需逐个授权；程序及运行数据目录权限由安装器配置。Linux 使用 systemd，macOS 使用 LaunchDaemon。安装、配对和 Windows → 群晖测试步骤见[测试指南](../docs/Windows源端服务测试.md)；架构与验收边界见[实施说明](../docs/源端直传与远程快照合成-0.5.md)。

一台设备连接同一中心只安装一个服务，可为多个源目录创建多个任务。每个任务各自配置 备份库与归档库、间隔和限速，按任务 ID 保存事件与执行状态；当前传输排队执行。Windows 安装只需指定程序目录，运行数据默认创建在其 `data` 子目录，仍支持显式 `-DataDir`。运行数据存放身份、队列和日志，应放在所有待备份目录之外。

## 命令

```sh
syncsrv-agent version
syncsrv-agent enroll --server https://center.example --data-dir /absolute/local/agent-data
syncsrv-agent run --data-dir /absolute/local/agent-data
syncsrv-agent status --data-dir /absolute/local/agent-data
```

`enroll` 提示输入一次性凭据，也支持 `--token-file`；身份私钥只保存在数据目录。局域网开发测试可显式 `--allow-http`，只允许私有数字 IP 或回环地址。Linux/macOS 安装的 `--service-user` 须是能读取 源目录的已有本机账户；群晖 DSM 7.2.2+ 使用原生 SPK，其他无 systemd 的 NAS 仍需厂商服务适配。

构建需要 Go 1.26+。从根目录运行 `python3 scripts/build-agents.py`，结果在 `artifacts/agent-releases/0.15.0-dev`。macOS FSEvents 需要 SDK/CGO，Windows/Linux 不需要额外运行时。

## 传输与可靠性

- 支持源端直连 SMB、SFTP、FTP、WebDAV 备份库。凭据按传输会话通过 X25519 + AES-GCM 加密下发；SMB 要求签名，SFTP 固定主机密钥，TLS 校验证书。
- 写入 备份库私有暂存后由源端回读校验，中心在备份库内移动提交；先保护旧版本到 归档库。源目录无需开共享；备份库的主机、端口、账号、路径须同时适用于源端和中心。
- SMB/SFTP 续传前核验已有前缀；FTP/WebDAV 保守采用完整重传。WebDAV 流式上传，不缓存整个文件到源端内存或中心磁盘。
- 完整清单和所有所需内容确认前不能推断删除；源端保留未确认队列，旧 ACK 不删除新代次。首次、重启、溢出和校准补扫，正常只观察变化范围。
- 事件捕获独立于上传/心跳。100ms 合并落盘窗口通过重启补扫修复；允许舍弃来不及备份的中间状态并记录。缺失根目录/读取失败/符号链接不能被当作全部删除。
- 无变更不扫描源目录；控制心跳约 60 秒。暂停任务仍保留事件。Windows 系统账户仍受显式拒绝、EFS 加密等限制，读取失败会报错；NAS 使用存储连接中的凭据。事件数据目录须在 源目录外的本机持久卷。

当前为开发测试版。Windows/Linux 实机服务、群晖 SPK 实机验收、其他 NAS 厂商套件、USN/FSEvents 历史游标、应用一致性快照、完整元数据保真、程序签名/公证、证书轮换、无人值守升级/卸载和容量压测仍需后续验证或实现。
