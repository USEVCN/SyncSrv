# SyncSrv Agent 0.16 发布说明

0.16 增加独立发布签名校验、中心兼容性检查、升级事务记录、服务配置回滚和中心心跳确认。升级由用户手动执行，不会在发现新版本时自动重启设备。

设备端同一执行批次中的文件共享限速器，可并行处理互不冲突的路径；中心统一分配全局流量额度。旧中心或没有限速作用域的旧命令继续采取保守的串行处理。

运行日志自动轮转，保留最近三组升级备份。SMB 实现已切换至包含目录解析安全修复的维护版本，Go 工具链固定为安全补丁版本 1.26.10，macOS 最低构建目标为 12.0。

安装、旧版本迁移和平台验收步骤见同包 README.md。正式启用前须完成目标设备的实机测试。
