# SyncSrv 0.4.3

修复 Linux 实机升级后浏览器可能缓存旧首页、继续请求已移除脚本而显示空白页的问题。HTML 入口、前端版本元数据与分发元数据明确使用 Cache-Control: no-store；带哈希的脚本及样式继续允许缓存。覆盖 GET、HEAD、直接页面路由和条件请求的回归测试。

H2 schema 仍为 1，Agent 仍为 0.16.0。支持已签署来源范围 0.4.0–0.4.2 在线升级，保留已有数据、密钥与配置。旧版浏览器已经缓存的入口需要首次使用强制刷新或带 ?v=0.4.3 的地址访问；新策略生效后可避免后续升级重复命中旧首页。

中心仍使用包内 Java 17。当前服务器是内网验证环境，生产启用仍需独立 HTTPS 审计锚点及业务负载验收。
