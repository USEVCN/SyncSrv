# 小文件传输与自动并发 · 0.13.0-dev

本版优化文件源 Agent → 实时备份 B 的控制请求、并发调度和清单收尾。不改变 B 的独立文件结构、归档版本或恢复格式。

## 小文件处理

- 不超过 1 MiB 的连续文件合并为小批次，每批最多 32 个文件、8 MiB；批量大小会缩小，保证有足够批次供并发工作。文件内容不在内存中打包，不走中心中转。
- 每批合并哈希清单、上传申请和完成确认。Agent 每个工作器复用独立存储连接；中心每个完成批次只建立一次连接，逐个核对文件类型及长度，再原子提交带逐文件哈希的回执。
- 元数据及回执使用批量数据库读取/提交。批内任一文件失败就不发布该批回执；重试时仍按文件验证已持久化前缀及完整 SHA-256。
- 源端变化阶段通知最多每秒一次，详细文件进度使用独立遥测。快速完成的批次也会在结束请求中补报最终计数。
- 清单收尾有至少 32 个待检查对象时，列举本任务直传暂存目录一次，按名称、类型、长度和已签名回执匹配；不会因缺失对象、列举错误或权限失败确认完成。较小批次继续逐个检查。
- 存储检查不再占用全局数据库锁；提交前重新确认会话、授权、源端修订及当前备份清单，检查期间被取消或替换的批次不能提交。

初始化仍需完成本次范围的元数据扫描，随后分批哈希与传输。流式目录发现、Agent 间打包传输未包含在本版。B→C 和恢复任务的并发不受这里的设置控制。

## 自动并发

新后端提供「自动调整文件并发」，默认开启、上限 16；可关闭自动模式使用原来的手动 1–16 设置。旧配置缺少新字段时使用默认值；旧 Agent 忽略新字段并继续按原手动数运行。

- 自动模式从最多 4 个并发文件起步；设置的上限小于 4 时遵守上限。
- 每 3 秒观察一次，至少有 4 个文件完成才试调。小文件占比至少 70% 时比较文件数/秒，否则比较完成字节数/秒。
- 有积压时每次试增 2 个并发；下一观察窗口完成速度未提高至少 5%，或单文件平均处理延迟上升超过 50%，回退并冷却 30 秒。
- 完成速度下降超过 25% 且延迟上升超过 50% 时减半；接近任务总限速时不继续增加。所有文件及回读共享任务限速。
- 失败仍停止整个观察批次，等待已有写入者关闭后才中止；下次重试从低并发重新开始。不会为了增加吞吐而跳过校验或同时启动第二个写入者。
- 未采集目标 NAS 的磁盘队列和 CPU；调整依据是端到端完成率、处理延迟、文件大小及限速消耗，不能据此断言 NAS 的具体瓶颈。

「执行详情」显示目标并发、上限、调整原因、平均文件完成速度，以及初始化、传输与校验、中心收尾耗时。初始化包括本次目录元数据发现和上报；传输包括哈希、连接、上传、回读和确认；中心收尾从处理结束请求计时至清单提交，不包含后续 B→C 归档或快照创建，也不包含最后 HTTP 往返和遥测保存。

## 升级

先加载新版后端，再更新 Agent 至 0.13.0-dev。Windows 在现有安装目录使用完整包的 `update.bat`，保留设备身份和事件队列；群晖在套件中心手动安装新版 SPK。无需重新配对。

新 Agent 通过 begin 响应中的 `batchDirect` 能力协商；连接旧后端时继续原来的逐文件接口，不发送新版统计字段。

## 验证和性能口径

受控对比：同一 Mac 上 256 个 4 KiB 文件、固定 4 并发、本地目标真实写入/同步/回读校验，模拟每个中心 HTTP 请求额外 2 ms 延迟。计时覆盖 Agent 元数据发现至中心 finish 接口返回，每组 3 次：

| 协议 | 平均耗时 | 控制请求数 |
|---|---:|---:|
| 原逐文件协议 | 1.161 秒 | 776 |
| 批量协议 | 1.017 秒 | 56 |

请求减少约 92.8%，受控场景耗时减少约 12.4%。这不是群晖实测、不是 B→C 完整备份吞吐，也没有用此结果宣称自动并发的收益。磁盘同步及逐文件文件系统操作仍有固定成本。

自动化检查包括逐文件回读、失败回执不可发布、同批原子确认、重复回执幂等、旧中心兼容、并发上下限/试探回退/限速冷却、取消等待所有写入退出，以及目录列举缺失对象仍拒绝提交。真实 Windows → 群晖的耗时需在升级后用同一批测试文件验收。

端到端 SMB 测试还发现既有存储端复制对 `STATUS_INVALID_DEVICE_REQUEST` 的识别缺失：SMBJ 将它映射成 `STATUS_OTHER`，导致不支持该指令的存储在历史恢复时失败。本版仅对复制路径中的 IOCTL 原始状态 `0xc0000010` 按“不支持”走现有回退；权限、参数和网络错误仍报错，已开始复制后的中断仍保留检查点。依据：[Microsoft SMB2 IOCTL 规范](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-smb2/c348a671-7750-49f8-9e61-cc59fa1a5701)。
