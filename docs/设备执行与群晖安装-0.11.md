# 设备执行与群晖安装（Agent 0.11）

一台设备向同一中心安装、配对一个 Agent。源目录、备份库、归档库和恢复库是目录角色，同一个 Agent 可同时监听 源目录、写入 备份库、归档到 归档库、执行目标时间点的 恢复库合成。现有任务和快照保持原格式。

## 执行选择

- 存储连接新增「优先执行设备」「设备上的本地目录」「允许中心中转」。原有 SMB/SFTP/FTP/WebDAV 连接用于跨设备访问、目录元数据与必要时中转。
- 源目录 → 备份库：原有源端直传保留；源目录与 备份库绑定同一 Agent 时，上传和回读校验改用备份库的本地目录。
- 备份库 → 归档库、备份库与归档库→恢复库：优先由目标的 Agent 执行；同设备在本地复制和 SHA-256 校验，跨设备由选中的 Agent 直接访问另一端的存储协议。目标 Agent 不可用时可选择源设备。
- 无可用设备时，按连接的中转开关使用现有 SMB 服务端复制或中心中转。设备确认直连未建立且未开始写入时，也允许中转。映射错误、内容不一致、权限错误必须修正，不会静默绕过。
- 已领取任务失联时停止放行，保留待确认状态；不会因为超时再启动一个中心写入者。Agent 停止后回报结果，才允许重试。暂停通过撤销执行租约、定期进度回执取消执行。
- 恢复库仍使用指定时间点的快照清单，从 备份库与归档库选择版本逐文件合成并校验；不是复制整个 归档库。恢复目的地要使用配置了设备映射的存储连接，输入其中的独立目录。
- 目前本地复制采用可校验续传和完整回读；没有启用 Btrfs reflink，也不承诺瞬时完成。文件内容不经中心，目录元数据、64 字节映射标识和小型恢复回执仍经中心。

## 当前 Windows + 群晖测试配置

1. 在 IDEA 重启后端加载新接口（先等当前备份完成），刷新网页。
2. Windows 已有 Agent：解压 0.11 完整包运行 `update.bat`，保留原设备身份、事件数据库和任务。不用再次配对。
3. 网页「备份设备 → 添加设备」生成配对凭据；「下载安装包」选择「群晖 DSM」及对应 CPU。
4. 群晖 DSM 7.2.2 及以上：套件中心 → 手动安装 → 选择 `.spk`。向导填写中心地址、设备名称及配对凭据。可信局域网 HTTP 测试需显式勾选允许。
5. 回中心授权新群晖设备。DSM 控制面板 → 共享文件夹 → 编辑 → 权限 → 系统内部用户，授予 `SyncSrvAgent` 所用共享的读写权限。Agent 使用 DSM 套件账户，不会修改其他账户权限。
6. 编辑 备份库、归档库、恢复库三个存储连接，选择同一个群晖设备，分别填写真实本地路径。例如 SMB `downloads/Backup/B` 对应的本地路径可能是 `/volume1/downloads/Backup/B`；卷号必须按实际设备核对。
7. 点击每个连接的「测试」。系统在 `.syncsrv/device-bindings` 写入 64 字节标识，再让 Agent 本地读取核对，防止 SMB 路径和本地路径指向不同位置。
8. 用独立测试目录完成新增、修改、删除备份和历史时间点合成。执行进度 hover 可见「设备本地执行 / 设备直接传输 / 中心中转」及原因，文件列表继续显示实时进度。

备份库、归档库、恢复库可以在同设备不同卷或共享中；它们必须互不包含，恢复库与所有 源目录、备份库与归档库分离。目录读写权限须同时满足存储连接账户与 Agent 账户。

## 群晖原生套件

- 提供 x86_64（amd64）与 armv8（arm64）SPK；不适用于 32 位 ARM、DSM 6 或低于 7.2.2 的系统。
- DSM 管理启动、停止、状态和开机启动，安装卷由套件中心选择；身份/队列位于 `/var/packages/SyncSrvAgent/var/state`。
- 升级使用套件中心手动安装新版 SPK，先停止旧进程，保留 var 中身份和队列；不会自动更新。卸载脚本也不主动清空状态。
- 程序为 Go 静态 Linux 二进制；SPK 不需要 Java、Node 或 Python。
- 通用 Linux 安装器仍要求 systemd；macOS 使用 launchd，Windows 使用 SCM。QNAP 原生 QPKG、其他 NAS 型号和 DSM 实机行为不在本次已验证范围。
- 既有 Linux 安装如仍使用旧服务单元的 `ProtectSystem=strict`，需为绑定的本地 备份库、归档库和恢复库配置 `ReadWritePaths`；本版新装单元使用 `ProtectSystem=full`，实际读写由服务账户权限和目录映射约束。

套件格式、安装 UI 和账户配置按群晖官方文档实现：

- https://help.synology.com/developer-guide/synology_package/wizard/WIZARD_UIFILES_v2.html
- https://help.synology.com/developer-guide/integrate_dsm/fhs.html

## 验证边界

本机自动化验证覆盖路由、禁止中心读取文件内容、本地复制与校验、断点复核、路径逃逸/符号链接、错误映射、签名设备隔离、未决任务禁止中转、持久回执去重、恢复目的子目录，以及安装包结构。群晖 SPK 的安装 UI、权限、开机启动和真实 NAS 吞吐量仍需实机验收。不要把构建成功当作群晖实机通过。
